## 배경

로봇팔을 다루는 사람은 두 종류다. **가르치는 사람**과 **감시하는 사람**이다.

가르치는 사람에게 필요한 것은 정밀함이 아니라 **직관**이다.
슬라이더로 6개 관절을 하나씩 맞추는 것보다 손으로 끌어다 놓는 편이 빠르다 (UR_05).
그렇게 만든 동작은 한 번 쓰고 버리는 게 아니라 반복해서 쓴다 (UR_06).

감시하는 사람에게 필요한 것은 **현재 상태가 화면과 같다는 확신**이다.
화면이 실물과 다르면 디지털 트윈은 오히려 위험하다.
그래서 UR_02 는 "볼 수 있다" 가 아니라 "**실제** 자세를 본다" 로 쓰였다.

그리고 둘 다에게 공통으로 필요한 것이 **멈출 수 있다는 보장**이다 (UR_04).
로봇을 처음 다루는 사람이 가장 먼저 묻는 질문이기도 하다.

## 용어

| 용어 | 뜻 |
|---|---|

| 직접교시 | 손으로 로봇을 끌어 동작을 가르치는 방식 (Direct Teaching) |
| 그리퍼 | 물체를 집는 집게 |
| 기준 자세 | 각 관절의 0°를 정의하는 자세 |
